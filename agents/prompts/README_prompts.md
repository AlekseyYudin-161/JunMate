# Системные промпты агентов A1–A6

Эталонные тексты системных промптов мультиагентного пайплайна (документация).
В текущей версии промпты встроены в соответствующие модули `agents/*.py`.
Вынос загрузки из этих файлов — в `ROADMAP` (разделение промптов и кода).

- `parser.md` — A1 (парсинг резюме)
- `track.md` — A2 (классификация трека)
- `matcher.md` — A3 (gap-анализ)
- `turn.md` — A4 (диалог-дозаполнение)
- `rewriter.md` — A5 (рендер hh.ru)
- `critic.md` — A6 (проверка фактологичности)
